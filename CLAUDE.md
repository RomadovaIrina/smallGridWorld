# Инструкции для Claude

Тестовое задание по RL: клеточная среда GridWorld (POMDP — агент видит только цвет клетки), агенты PPO и Discrete SAC.
Пользователь — новичок в RL. **Код должен быть максимально простым, «студенческим»**:
- классы с методами `train()`: `alg = PPO(cfg); alg.train(); alg.save()`;
- конфиги — обычные словари прямо в ноутбуках, без dataclass и без CLI-скриптов;
- без вложенных функций, без «умных» абстракций, без аннотаций типов;
- не ускорять и не оптимизировать код без явной просьбы (векторизация — отдельная задача на потом);
- коммитить только по просьбе пользователя, не пушить без просьбы.

## Где что лежит

- `src_v2/gridrl_v2/` — **активный код** (в `pyproject.toml`: `module-root = "src_v2"`, `module-name = "gridrl_v2"`):
  - `envs/gridworld.py` — среда с one-hot цветом; `envs/mnist_env.py` — её копия, где цвет — картинка цифры MNIST;
  - `envs/setups.py` — `make_env(h, w, n_colors, obstacle_fraction, seed, mnist=False)`, BFS, оптимум;
  - `models/ppo.py`, `models/dsac.py` — алгоритмы; `utils.py` — сохранение и картинки (карта, тепловая карта, GIF).
- `src_v2/test_task.ipynb` — задачи 1–2: обучение PPO и DSAC с памятью (GRU) на 4 средах.
- `src_v2/test_task_v2.ipynb` — обучение без памяти (MLP) и красивые графики (среднее + полоса) по `runs/`.
- `src_v2/mnist_task_v1.ipynb` — задача 3: то же на MNIST-среде.
- `src/`, `src_v2/gridrl/`, `src/gridrl_v2/` — старые версии, **не трогать и не использовать**.
- `runs/` — метрики и веса прогонов (не в git), `outputs/` — картинки для отчёта (в git).

## Задача на машине с RTX 3050: обучить всё на GPU

### 1. Окружение

Нужен драйвер NVIDIA ≥ 560 (проверить: `nvidia-smi`). Через uv:

```bash
uv sync --extra cu126
uv run python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
uv run python -m ipykernel install --user --name petr --display-name "Python (petr)"
```

Ноутбуки ждут Jupyter-ядро с именем `petr`, последняя команда его создаёт. Должно напечататься `True` и имя карты.
MNIST скачивается сам при первом запуске в `data/mnist` (~10 МБ).

Проверить, что всё работает: `uv run pytest` (30 тестов).

### 2. Обучение — строго по очереди, по одному ноутбуку

Ноутбуки сами выбирают `cuda`, если она доступна (`DEVICE` в первой ячейке). Запускать в фоне, вывод сохраняется в ноутбук:

```bash
uv run jupyter nbconvert --to notebook --execute --inplace --allow-errors \
    --ExecutePreprocessor.kernel_name=petr --ExecutePreprocessor.timeout=-1 src_v2/test_task.ipynb
```

Порядок:
1. `src_v2/test_task.ipynb` — PPO и DSAC с памятью на 4 средах (главное).
2. `src_v2/test_task_v2.ipynb` — без памяти + графики (читает `runs/` из шага 1).
3. `src_v2/mnist_task_v1.ipynb` — MNIST.

**Время.** На CPU PPO — ~5 минут на среду; DSAC на картах 10x10 — долго (старая версия шла ~2 часа на карту).
DSAC недавно переписан (обучение на целых эпизодах) и **ещё ни разу не прогонялся полностью** — сначала
проверь его коротким прогоном на маленькой карте (например, Env2, 100 эпизодов) и сообщи пользователю,
сколько это заняло и учится ли он, прежде чем запускать долгие прогоны. Сети маленькие, поэтому GPU может
ускорить не сильно — это нормально, сравни время с CPU и сообщи пользователю.
