# RL for GridWorld

Тестовое задание: частично наблюдаемый GridWorld, on-policy (PPO) и off-policy (Discrete SAC) агенты с рекуррентной памятью.

Автор: _ФИО_

## Установка

Нужен [uv](https://docs.astral.sh/uv/). Нужную версию Python uv скачает сам (см. `.python-version`).

```bash
uv sync --extra cpu      # машина без NVIDIA GPU
uv sync --extra cu126    # машина с NVIDIA GPU (CUDA 12.6; нужен драйвер NVIDIA >= 560)
```

Устройство выбирается автоматически (`--device auto`: CUDA, если доступна, иначе CPU).

## Тесты

```bash
uv run pytest
```

## Организация кода

```
src/gridrl/
  envs/
    grid_core.py   # чистая numpy-логика переходов (батчевая — основа для векторизации)
    gridworld.py   # GridWorldEnv (gymnasium.Env), зарегистрирована как GridWorld-v0
    setups.py      # генерация карт и сетапы 1–4 из задания, оракул-бейзлайн через BFS
    render.py      # отрисовка карты (rgb_array / ansi)
  utils.py         # выбор устройства, сиды
tests/             # тесты среды
```

## Среда

- Цвета наблюдения: `0..n_colors-1` — пол, далее цель, препятствие, стена; наблюдение — one-hot размерности `n_colors + 3`.
- Действия по часовой стрелке: 0 вверх, 1 вправо, 2 вниз, 3 влево.
- Награда 1 за попадание в цель (эпизод завершается), иначе 0.
- `see_obstacle=True` (по умолчанию): при ударе о стену/препятствие агент видит её цвет и остаётся на месте.
- `obs_mode="coords"` — отладочное наблюдение: one-hot позиции агента (MDP).

### Допущения (в задании не оговорены)

- Лимит эпизода — `4·h·w` шагов (truncation).
- `pos_agent`-массив имеет форму `(h, w)`, как остальные карты (в тексте задания указано `(w, h)` — считаем опечаткой).
- В сетапах цель — случайная свободная клетка (по сиду), старт — равномерно по свободным клеткам, кроме цели.
- Препятствия расставляются так, что все свободные клетки связны.
- При одинаковом сиде сетапы 3 и 4 получают одну и ту же карту препятствий и цель и различаются только покраской пола. Так сравнение 7 и 4 цветов становится контролируемым.
