# Аудит кода (ветка `work/rl-experiments-audit`)

Исходная версия: коммит `9cc81ef` (main). Активный код — `src_v2/gridrl_v2/`.
Окружение сервера: Ubuntu 24.04, Python 3.12.3, torch 2.14.1+cu126, CUDA доступна (RTX 3090), gymnasium 1.4.0, numpy 2.5.4.

### Известные ограничения (не исправлены)

- Один сид на эксперимент: разброс между сидами не оценён, полосы на графиках — разброс внутри одного прогона.
- Температура α в DSAC фиксированная (0.005), автоподбора нет.
- У PPO лоссы записываются один раз на пачку из 10 эпизодов (одинаковые у всех эпизодов пачки).
- В DSAC каждый эпизод из батча весит одинаково, независимо от длины (лосс — среднее по шагам эпизода, затем по эпизодам).
- Наивная реализация, без векторизации: DSAC на картах 10x10 учится долго.
